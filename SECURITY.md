# Security

Use the GitHub repository's private vulnerability reporting option when enabled. Otherwise open a minimal issue requesting private contact with the maintainer. Withhold exploit payloads, tokens, signed URLs and private media until a private channel is established.

Use one trusted operator per private cache. Never expose the stdio process or provider admin console to the public network. Limit keys to douyin:read, use guest-only identities and retain only media you have rights to save. The adapter observes the platform save setting when selecting its download endpoint and reports it separately for public playback. Keep the operating system, codecs, engine and locked dependencies up to date.
