# Security

Use the GitHub repository's private vulnerability reporting option when enabled. Otherwise open a minimal issue requesting private contact with the maintainer. Withhold exploit payloads, tokens, signed URLs and private media until a private channel is established.

Use one trusted operator per private cache. Never expose the stdio process or provider admin console to the public network. Keep ordinary read keys separate and the rotating pool guest-only. For explicitly configured [local profile login](docs/providers/douyin.md#optional-local-login-for-public-uploads), reserve the identity, protect its dedicated operator key and retain only media you have rights to save. The adapter observes the platform save setting when selecting its download endpoint and reports it separately for public playback. Keep the operating system, codecs, engine and locked dependencies up to date.
