# Roadmap

The v0.1.0 release gate covers public Douyin video, local processing, SQLite, MCP, CLI and the first Codex plugin. Remaining live checks and gaps are tracked in IMPLEMENTATION_STATUS.md.

After v0.1.0, investigate native public video acquisition, Bilibili, YouTube and Xiaohongshu adapters, local MP4 and audio inputs, other agent clients, media knowledge bases and cross-video retrieval. Each adapter needs permission boundaries, measured contracts and platform-specific test coverage.
