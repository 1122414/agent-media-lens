# Compare how an agent inspects a shared video

The maintainer clarified on 2026-11-18 that users paste a platform link so their agent can examine the video in the conversation. To compare tools, start with a supported public share and ask what appears on screen at a particular moment and what the speaker says. Check whether the agent can open a real sampled image, read the timed transcript and cite the actual sample time without operating a browser. The [release demo](../../demo/README.md) records this workflow on a public Douyin video. The [MCP implementation](../../../apps/mcp-server/main.ts) returns JPEG content and its time label to the client.

Two earlier comparisons counted a saved file or a finished report as the user's goal. A downloader such as the [upstream MCP service](https://github.com/Evil0ctal/Douyin_TikTok_Download_API/blob/main/documents/en/12-mcp.md) overlaps at acquisition; a report generator overlaps at the output. For a direct substitute, verify what visual and speech evidence the agent itself can inspect. Record initial setup separately from routine use. The [Douyin](../../providers/douyin.md) and [Bilibili](../../providers/bilibili.md) adapters need a configured reader service and usable guest access. When a platform denies access the agent reports the failure.

The initial documentation review found three delivery paths. [BibiGPT’s API](https://docs.bibigpt.co/api-reference/introduction) documents Bilibili visual jobs that return screenshot URLs to Pro callers. [Bilibili-douyin-notes](https://github.com/lucky-Luor/bilibili-douyin-notes/blob/59fadaae2eea040bfeb578c541e27782115cb1fb/SKILL.md) has the agent open local candidate images to choose screenshots. [Envoy’s acceptance matrix](https://github.com/regrevia/Envoy/blob/main/docs/acceptance/platform-coverage-matrix-2026-10-21.md) records two images and 51 timed speech segments on a Douyin sample using a headless browser.

In the [same-link benchmark](../../development/2026-11-18_agent-video-comparison.md), a queried second fell between samples and a cut changed the answer on both longer videos. Record the requested time, returned time and visible detail. Decode the frame covering the target timestamp independently. Score native evidence and an explicit seek of the other tool’s own media separately. In one run across five timestamps, the notes screenshot selector favored later illustration frames or rejected times outside transcript anchors. Seeking its input with FFmpeg recovered all five. BibiGPT required authentication before returning media evidence, so the credentials check established no accuracy result. Check the corresponding audio window when a user asks about speech at a given second. In the tutorial, an unflagged transcript segment covered a quiet gap.

Check which edition a repository ships before carrying a hosted service's platform list or screenshot features into a self-hosted comparison. The GPL-3.0 BibiGPT v1 README limits that edition to Bilibili and YouTube, even though the repository description names Douyin. The MIT-licensed BiliNote documents both Chinese platforms, local transcription and screenshot output. Its HTTP route accepts note-generation jobs with a screenshot option. This follow-up checked documentation and the route definition only. [BibiGPT v1 README](https://github.com/JimmyLv/BibiGPT-v1#readme) · [BiliNote](https://github.com/JefferyHcool/BiliNote#readme) · [HTTP route](https://github.com/JefferyHcool/BiliNote/blob/master/backend/app/routers/note.py)

In a subsequent [local BiliNote 2.4.5 run](../../development/2026-11-18_bilinote-local-comparison.md), Bilibili speech at both target times was directly available in the API result. The backend's six-second image grid missed the 32-second star count. A fresh note requesting two explicit screenshot markers delivered both exact JPEGs over HTTP, including the off-grid 32-second image. The generated captions omitted the details visible in those same files. Check the returned images, transcript segments and chat answer independently. Record whether the agent queried existing evidence or generated a new note to request another frame. Both uncredentialed Douyin links failed during detail parsing in this installation. The response did not establish why.
