# AgentMediaLens v0.1.0

Give an agent a public Douyin video link to obtain timestamped speech, frame images, on-screen text and a local Markdown report. This source release includes a separate Codex marketplace archive. The CLI and MCP share the same local runtime.

## Architecture and interfaces

TypeScript orchestrates the provider, SQLite task lifecycle, cache and evidence reads. The Python 3.12 worker runs FFmpeg, faster-whisper and Tesseract. Apps live under apps/, core code under packages/core/, the worker under workers/, deployment under providers/douyin/ and the Codex integration under plugins/codex/. Evil0ctal v5.1.11 is the optional HTTP provider. The independent native adapter identifies and expands shares.

The CLI supports doctor, config, identify, resolve, analyze, task, transcript, frames, result and cleanup. The ten stdio tools are media_resolve, media_analyze, media_get_task, media_get_transcript, media_list_frames, media_get_frame, media_get_frames, media_get_result, media_save_analysis and media_cleanup. Source files and work products are isolated per task. By default the system admits one video at a time, up to 600 seconds and 500 MB, and caches eligible video files for seven days.

## Install and use

Install Node 24.12+ (24.x), pnpm 11.5, Python 3.12, uv, FFmpeg/ffprobe and Tesseract with Simplified Chinese and English data. Clone the tag, then install the local runtime:

```sh
git clone --branch v0.1.0 https://github.com/1122414/agent-media-lens.git
cd agent-media-lens
pnpm install --frozen-lockfile
uv sync --frozen --python 3.12
pnpm build
sh scripts/install-launchers.sh
export PATH="$HOME/.local/bin:$PATH"
codex plugin marketplace add .
codex plugin add agent-media-lens@agent-media-lens-local
```

Start the optional v5 provider and configure its read-only key in the CLI or Codex process. Run `media-lens doctor`. Use `media-lens analyze "$SHARE_URL" --keep-playback` to keep media you have rights to save, or ask the installed plugin to summarize a share and cite frames. Resolve reports the platform save setting and available rendition. For a container build, run `docker compose build` and `docker compose run --rm lens --help`. On hosts with standalone Compose use `docker-compose`.

The attached plugin archive can also be extracted into a local marketplace directory. After installing the runtime launchers above, add that directory with `codex plugin marketplace add <directory>`, then run the same plugin installation command. Ensure the Codex process can find media-lens-mcp on its PATH.

## Limits and next steps

The guest needs access to the work and its media. Deleted, private, login-only or refused content can be unavailable. A publicly served rendition is a platform encode; camera masters are outside the service. Native-only metadata and acquisition, photo album analysis, other platforms, local file inputs and additional agent integrations remain on the roadmap. Automated transcription can mishear music and technical vocabulary, OCR can misread overlays and sparse frames can miss brief shots. CPU inference was exercised on the development host. CUDA throughput and accuracy require separate hardware validation.
