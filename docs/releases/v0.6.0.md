# AgentMediaLens v0.6.0

把公开的抖音或 B 站链接发给 Codex 或其他支持 MCP 的 Agent。配置好访客读取服务后，Agent 不开浏览器就能看关键帧、读口播。在同一对话里追问“第 32 秒屏幕上写了什么？”时，Agent 会从已完成的任务按需取出当时实际显示的画面，并返回附近的口播转写和语音活动。需要核听时，还能取前后各两秒的原声。

## 两个实测追问

| 追问 | 画面和口播给出的答案 |
|---|---|
| B 站 Mika 讲解，第 32 秒是多少颗星？ | 画面中星标旁是 **4,898**。30.72–32.32 秒的口播转写是「快五千顆星」。此前按最近关键帧查询会取到 39 秒，那时已切到账号表格。[原视频 · 00:32](https://www.bilibili.com/video/BV1Q34P6vEzR/?t=32) |
| 抖音后台教程，第 43 秒打开了哪个页面？ | **改密码页**。标题是「安全」，下方有三个密码输入框和蓝色「下一步」按钮。此前最近的关键帧是 51 秒的「基础信息」页。43 秒画面底部有改密码说明，41–45 秒原声没有检出语音活动。[原视频](https://www.douyin.com/video/7422312100527148322) |

本次用三条公开链接、五个固定时间点复测。最近关键帧命中 3/5，精确追问命中 5/5。三个任务在初次分析后都已清理原片，追问时通过访客服务重新取得了媒体。平台之后能否继续访问会影响复查，歌词等转写也仍可能识别出错。[完整复测记录](https://github.com/1122414/agent-media-lens/blob/v0.6.0/docs/development/2026-11-18_on-demand-moments.md)

## For MCP clients

Call `media_get_moment` with a completed video’s `taskId` and a `timestamp` in seconds. The response contains the displayed JPEG, its presentation time, nearby transcript segments and voice activity. Set `includeAudio` to `true` for the original audio window, up to four seconds long. Keyframe tools remain available for overviews. [MCP contract](https://github.com/1122414/agent-media-lens/blob/v0.6.0/docs/architecture/data-contracts.md)

## 安装

下载 `agent-media-lens-v0.6.0.tar.gz` 并解压，启动 Docker 和 Compose v2+，在解压目录运行 `./media-lens install` 和 `./media-lens doctor --local`。配置抖音或 B 站的访客读取服务后，在新会话里粘贴链接即可。较小的 `agent-media-lens-codex.tgz` 用于已有运行时的 Codex 本地插件市场。`SHA256SUMS` 可以校验安装包、演示视频及字幕。[中文安装指南](https://github.com/1122414/agent-media-lens/blob/v0.6.0/README.zh-CN.md#install) · [English installation guide](https://github.com/1122414/agent-media-lens/blob/v0.6.0/README.md#install-on-macos-or-linux)
