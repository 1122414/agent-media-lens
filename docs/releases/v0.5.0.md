# AgentMediaLens v0.5.0

Give Codex a public Douyin or Bilibili link and ask for a timestamped Markdown report. See the [80-second real workflow](https://github.com/1122414/agent-media-lens/blob/v0.5.0/docs/demo/README.md). The previous public release was v0.1.0; the intervening plugin versions were development milestones.

**Install:** download the versioned source bundle, extract it, start Docker with Compose v2+, and run `./media-lens install` inside the extracted directory. Keep this directory. The installer builds the runtime and registers the local marketplace if Codex CLI is installed. For other stdio clients pass `--no-codex`. Verify the runtime with `./media-lens doctor --local`.

- **agent-media-lens-v0.5.0.tar.gz:** full checkout for installation; no prebuilt image or model weights.
- **agent-media-lens-codex.tgz:** local marketplace descriptor, plugin skill, stdio configuration and license only. This smaller archive needs the runtime/launchers installed separately. Official OpenAI directory inclusion is not verified.
- **walkthrough.mp4**, **captions.zh.vtt** and **SHA256SUMS:** captioned demo and release asset checksums.
