# Platform adapter roadmap

Douyin public video is the first integration. A new platform needs an owner-approved URL and CDN allowlist, explicit visibility and download-permission evidence, typed metadata, a real public integration test, and fixtures for revoked access. Bilibili guest video and Douyin static/live albums have live acceptance coverage. Bilibili currently processes a single progressive MP4 for the requested part. Xiaohongshu has an [experimental guest adapter](../providers/xiaohongshu.md): login/error handling verified live, positive media paths verified with fixtures only. YouTube remains a candidate. Local files and audio require a separate trusted-input boundary. See the [project roadmap](../../ROADMAP.md).
