# Development setup

For the Docker quickstart see the [README](../../README.md). For a **native developer install** prepare Node 24.12+ (24.x) or 26.x, pnpm 11.5.0, uv, FFmpeg/ffprobe and Tesseract with eng and chi_sim. From the checkout run `sh scripts/init-native.sh`; uv provisions Python 3.12. Run `~/.local/bin/media-lens doctor --local`, then register the local marketplace and plugin as shown in the README. On native installs `media-lens install` and `doctor --fix` repeat this setup. Missing system prerequisites are reported; nothing runs sudo or edits your shell profile. Use one private cache per operator. The Node and Python environments are pinned independently by pnpm-lock.yaml and uv.lock. The development checkout is the installation root for both launchers; keep it in place after linking.

To isolate settings, write a local JSON file with cacheDir, model and ocrLang, and set MEDIA_LENS_CONFIG to its absolute path. No secret belongs in this file. A provider key is needed only for live resolution and download. Run [the offline suite](testing.md) first and configure the [provider](../providers/douyin.md) separately.
